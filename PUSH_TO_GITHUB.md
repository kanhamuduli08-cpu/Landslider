## 🐛 Troubleshooting

### If push fails with "no remote"
```bash
# Check remotes
git remote -v

# If empty, add remote
git remote add origin https://github.com/YOUR_USERNAME/skyrescue.git

# Then push
git push -u origin main
```

### If push fails with "permission denied"
```bash
# Use HTTPS instead of SSH
git remote set-url origin https://github.com/YOUR_USERNAME/skyrescue.git

# GitHub may prompt for username/password
# Use Personal Access Token as password (not your GitHub password)
```

### If you need to change username
```bash
git config user.name "Your Name"
git config user.email "your.email@example.com"
```
